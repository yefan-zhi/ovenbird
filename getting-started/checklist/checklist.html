    Checklist¶

    Here is a quick checklist before printing. Click to update. "localStorage" is used to save the progress. Feel free to refresh the page.

    /

    Toolpath¶

    The correct layer height and extrusion width are used in slicing.

    If the component is for a discrete assembly, the sides are correctly offset as surface or as Toolpath.

    Smooting and overfill optimizations are properly performed.

    The local and global overhangs are printable.

    The layers are simplified to have minimal numbers of curves.

    The seams are aligned properly for continuous printing / nonstop printing.

    Set-up Compatibility¶

    If needed, the bed adhesion is added.

    The Toolpath is placed properly on the bed, within printable area. It is upright (not flipped).

    The Toolpath is visualized before printing.

    If Using G-Codes...¶

    The correct GCode profile is used.

    Preferably, the G-Code is verified through a third party software (e.g. PrusaSlicer).

    If Using a Robot...¶

    The file is free of errors.

    A proper resolution is used and the file does not exceed memory limit (for example, 50,000 points).

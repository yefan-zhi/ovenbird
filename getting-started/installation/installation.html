    Installation¶

    Ovenbird is a plug-in for Grasshopper, the graphical algorithm editor for the 3D modeling software of Rhino. Ovenbird works on Grasshopper in Rhino 7/8 for Windows and Rhino 8 for Mac.

    Install from Rhino's Package Manager (Recommended)¶

    In Rhino, type PackageManager to open the Package Manager (previously known as Yak). Search Ovenbird and install from there. Video tutorial.

    Packages installed this way have higher startup priority then those in the Components Folder. However, we still recommend that you delete the Ovenbird in your Components Folder if you have previously installed manually from food4Rhino.

    Install manually from food4Rhino¶

    Download Ovenbird from food4Rhino. To install, unzip the package. In Grasshopper, go to File → Special Folders → Components Folder. Save the unzipped folder there and delete the previous one if you have it. Make sure the .gha file is unlocked. Restart Rhino and Grasshopper. Video tutorial.

    Change Log¶

    All versions available here.

    Ovenbird 2¶

    Version 2.4.2.1 - 2026-11-11¶

    • Core function introduced: Overhang optimization on toolpath.
    • Memory and performance optimization.
    • Overhang and overfill visualized as meshes.
    • Runs on Mac now.
    • Package manager supported.
    • Algorithm and UI updates.
    • Example files and documentation site updates.

    Version 2.2.5 - 2026-05-21¶

    • Toolpath Transformation bug fix.
    • Optional local overhang value output.

    Version 2.2.4 - 2026-04-29¶

    • Join Layers support list input.

    Version 2.2.3 - 2026-04-14¶

    • Locker geometry update.
    • Optimal coloring scheme for contrast.

    Version 2.2.2 - 2026-03-02¶

    • GCode components cache removed and resolution reduced to reduce lagging.

    Version 2.2.1 - 2026-02-22¶

    • Flip Toolpath. Sub Layers.
    • Clipper2 update. Offset results are simplified with a larger tolerance for better performance.

    Version 2.1.9 - 2026-02-10¶

    • Visualization includes vertex normal computation.
    • Rhino 8 Open the Doc bug fix.

    Version 2.1.8 - 2026-01-30¶

    • Infill adds max loop count.

    Version 2.1.7 - 2026-01-29¶

    • Minor bug fix.

    Version 2.1.6 - 2026-01-23¶

    • Simplify Region and Merge Regions with alignment.
    • Quick bug fixes.

    Version 2.1.5 - 2026-01-14¶

    • Minor display update.
    • Save gradient legend as image.

    Version 2.1.4 - 2025-11-27¶

    • Display option update.
    • Unwrap overhang distribution.
    • Reorder Toolpath bug fix.

    Version 2.1.3 - 2025-11-13¶

    • Split Depth.
    • Minor bug fixes.
    • Minor adjustment to Toolpath Mesh.

    Version 2.1.2 - 2025-11-04¶

    • Reorder Toolpath update with new Google OR-Tools.
    • Rotary slicing new option.
    • Minor display improvement.

    Version 2.1.1 - 2025-09-17¶

    • Collision detection in Continuous Printing.
    • Documentation site.
    • Bug fixes.

    Version 2.1.0 - 2025-08-07¶

    • Multi-Material Printing.
    • Infill.
    • More parameter options.
    • Example files update.

    Version 2.0.6 - 2025-07-21¶

    • Wrap Toolpath more options.
    • Nonstop Printing improved.
    • Mirror more options.
    • Massive toolpath union/join/intersect.
    • Bug fixes.

    Version 2.0.5 - 2025-07-17¶

    • SubToolpath for animation.

    Version 2.0.4 - 2025-07-05¶

    • Nonstop Printing for common printing setups.
    • Bed Adhesion.
    • Split and Join Layers.
    • Toolpath Boolean adds smart filter and relative or absolute.
    • Smooth Toolpath and Overfill Optimization adds locker.
    • Mirror Toolpath.

    Version 2.0.3 - 2025-05-17¶

    • Bake geometry with color and in current layer.
    • Toolpath Mesh algorithm update.
    • Polyline Toolpath supports simplification.
    • Unwrap adds local orientation and height information.
    • Bug fix.

    Version 2.0.1 - 2025-05-01¶

    • Ramp curve height calculation bug fix.
    • Parallel visualization with non-uniform layer height bug fix.
    • Unwrap adds local layer height.

    Version 2.0.0 - 2025-04-22¶

    • Initial release of Ovenbird 2 plug-in.
    • Redeveloped using C#, no prerequisites needed.
    • Example files embedded.
    • Increased performance and stability.
    • New user interface with improved usability.
    • Overhang Optimization not supported on Mac.
    • Multi-material Printing not implemented.
